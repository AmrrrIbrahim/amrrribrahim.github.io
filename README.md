# amribrahim.work

Personal website of Amr Ibrahim, built with [Astro](https://astro.build).

- `npm install` – install dependencies
- `npm run dev` – local preview at http://localhost:4321
- `npm run build` – production build into `dist/`

Page titles and descriptions live in `src/content/pages/en/*.md`. Home and Experience text lives in `src/data/en/`.
Every push to `main` publishes the site to GitHub Pages.
